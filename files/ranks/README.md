# Ranks folder

This directory is for rank PNG assets. Upload your PNG images into this folder (one flat directory). Once the PNGs are added they will render on GitHub at `https://github.com/xillyware/rritvri/tree/main/files/ranks`.

Guidance:
- Keep filenames lowercase and use hyphens or underscores instead of spaces (e.g., `iron-1.png`).
- If you want placeholder (zero-byte) PNGs added by me, say so and I'll create them.
